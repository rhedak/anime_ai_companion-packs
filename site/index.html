Picture packs

Downloadable picture packs for anime_ai_companion. The list the app reads is index.json (format described by index.schema.json). Each pack file is a GitHub Release asset linked from that list.

Packs that have a published release are listed in index.json. Source frames live in the packs repository and are not themselves the download. Franzi's outfits are franzi-casual, franzi-pajamas, and franzi-bikini. miku is a separate character. Risa's outfit here is risa-bikini (her dress ships with the app). Draconia Malfoid's outfits are draconia-uniform, draconia-vest, and draconia-gown; she is not an outfit of Franzi.
